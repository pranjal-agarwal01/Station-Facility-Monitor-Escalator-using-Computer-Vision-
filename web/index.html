How it works

  1. People. YOLO11n finds people inside the marked region every few frames; a small tracker keeps their boxes in between.
  2. Surface motion. Dense optical flow (Farneback) measures how the handrails and steps move, with people masked out, so someone walking on a stopped escalator does not count as motion.
  3. Checks. Motion must be mostly vertical and both handrails must agree on the direction.
  4. Decision. A state machine with separate enter and exit thresholds turns ~2 seconds of evidence into a stable state: working, stopped with people on it (fault) or idle.

The full Python version adds live RTSP cameras, webhook alerts, a CLI and a test suite: see the repository.
